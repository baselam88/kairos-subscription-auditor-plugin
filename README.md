# Subscription Waste Auditor

Scans a pasted statement/subscription list for unused, duplicate, or silently-renewed subscriptions (benchmark waste ~$50-200/mo, labelled estimate).

A free plugin from KAIROS AI Systems — one focused tool that does one job well for a
small business: no suite to learn, no setup project, no account required beyond your
agent host.

## What it does

Output: waste table with per-item verdict (keep / cancel candidate / duplicate), renewal dates, and total recoverable estimate — labelled estimate throughout.

## How to use it

Add this plugin to a compatible agent host (Cursor, Grok Bot, or another
agent-plugins host), then ask in plain language, for example:

> Use the Subscription Waste Auditor to help me: scans a pasted statement/subscription list for unused, duplicate, or silently-renewed subscriptions (benchmark waste ~$50-200/mo, labelled estimate) — I'll paste the details.

The plugin works from the facts you give it — your services, your prices, your
records. It never invents a number, a policy, or a result; anything it projects is
labelled an estimate with its basis. Drafts that would go to a customer stay drafts
until you approve them.
